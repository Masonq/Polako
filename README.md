# polako.
Majice, duksevi i hudi sa frazama. FastAPI + PostgreSQL + React/Vite, jedan Docker kontejner + baza.

Deploy na serveru: `bash deploy.sh` (pravi `.env` pri prvom pokretanju, log ide u `logs/deploy.log`).
Telegram obaveštenja o porudžbinama: upiši `TG_BOT_TOKEN` i `TG_CHAT_ID` u `.env`, pa ponovo `bash deploy.sh`.
